# Лабораторная работа №5 — Введение в Vue 3

Одна HTML-страница с семью мини-заданиями по Vue 3. Каждое задание — отдельный компонент, переключение между ними — вкладками «Задание 1…7». Vue подключён через CDN, сборщик не нужен.

**Автор:** Илья Абрамов, группа ФИТ-241

**Опубликованная страница:** https://abramov222.github.io/vue-lab-5/

## Задания

| № | Компонент | Что показывает | API |
|---|-----------|----------------|-----|
| 1 | `Task1` | Приветствие обновляется при вводе имени: `data()`, `v-model`, интерполяция | Options API |
| 2 | `Task2` | Счётчик на `ref`, увеличение по `@click` | Composition API |
| 3 | `Task3` | Кнопка «Показать/Скрыть описание»: `v-if` / `v-else` | Composition API |
| 4 | `Task4` | Список товаров через `v-for` с номером и уникальным `:key` | Composition API |
| 5 | `Task5` | Форма «имя + возраст»: `v-model`, `@submit.prevent`, добавление в массив и очистка формы | Composition API |
| 6 | `Task6` | Число, его квадрат и куб через `computed` | Composition API |
| 7 | `Task7` | Часы: таймер запускается в `onMounted`, `watch` пишет каждое обновление в консоль, приветствие зависит от часа | Composition API |

Composition API используется через функцию `setup()` (без `<script setup>`, так как сборщика нет). В задании 7 таймер останавливается в `onUnmounted`, чтобы он не продолжал работать после переключения на другую вкладку.

## Запуск

Сборка не требуется: откройте `index.html` в браузере или запустите локальный сервер в папке проекта, например:

```bash
npx serve .
```

Сообщения задания 7 смотрите в консоли браузера (F12 → Console).
